# 🎬 Movie App

A responsive movie web application built with **HTML, CSS, and JavaScript**.

The project provides a simple and attractive interface for browsing movies, searching for movies, and exploring movie-related content.

---

## 📌 About The Project

**Movie App** is a front-end web application created as part of my front-end development practice.

The main goal of this project is to build a modern, responsive, and user-friendly movie website using core web technologies without relying on frameworks.

The project focuses on:

- Building responsive layouts
- Creating reusable UI sections
- Working with JavaScript to add interactivity
- Organizing front-end project files
- Creating an attractive user interface
- Practicing HTML, CSS, and JavaScript

---

## ✨ Features

- 🎬 Browse movies
- 🔍 Search for movies
- 🖼️ Display movie posters and images
- 📱 Responsive design for different screen sizes
- 🎨 Modern and user-friendly interface
- ⚡ Interactive JavaScript functionality
- 🧭 Easy navigation between sections
- 📄 Organized movie-related content

---

## 🛠️ Technologies Used

### HTML5

Used to create the structure and content of the application.

### CSS3

Used for:

- Styling the website
- Responsive design
- Layout and positioning
- Colors and typography
- Creating a modern user interface

### JavaScript

Used to add interactivity and dynamic behavior to the application.
