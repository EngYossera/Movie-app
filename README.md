# 🎬 Movie App

A responsive movie web application built with HTML, CSS, and JavaScript.

## 📌 About The Project

Movie App is a front-end web project that provides a simple and attractive interface for browsing movies and exploring movie-related content.

The project was created as part of my front-end development practice to improve my skills in building responsive websites and working with JavaScript.

## ✨ Features

- 🎬 Browse movies
- 🔍 Search for movies
- 📱 Responsive design
- 🎨 Modern and user-friendly interface
- 🖼️ Movie images and posters
- ⚡ Interactive JavaScript functionality
- 📄 Movie details

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Font Awesome
